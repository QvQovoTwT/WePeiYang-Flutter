#### 个人主页 `profiles/`
***所有的帖子依旧按照原先微北洋的帖子数据结构响应***

<br>

1.  `GET` 获取用户发过的帖子 （*访客视角*） `/api/v1/b/profiles/{userId}/public-posts`

    根据用户ID查询发布过的帖子，默认依据时间排序，支持分页;

    会判断并返回主页可见性;

    会过滤校务和主人设置的不可见帖子;

    可以用在个人主页的访客视角，关注动态（对多个人依次获取，最后按时间排序），访客查看他人主页
        
    如果有人的关注量特别大，多次调用接口可能要长时间，目前设想通过分页功能，减少每次调用的传输数据量，也可以前端并发查询

    <br>

    **param list**
    - `uid` Long uid 
    - `page_disable` Integer 是否取消分页 默认`0`，不取消
    - `page`  Integer 页码 默认`1`
    - `page_size`  Integer 页大小 默认 `10`
    - `offset`  Integer 页偏移 默认 `0`

    <br>

3. `PUT`设置自己单个帖子的可见性`/api/v1/b/profiles/{id}/visibility`

    在个人主页设置自己某条帖子的可见性，原来所有帖子默认**不可见**

    无论之前的可见状态是什么，都会完成可见性的更新

    <br>

    **param list**
    - `visibility` Integer  `0`不可见，`1`可见

    <br>

    **返回示意**
    ````
    {
        "code": 200,
        "data": null,
        "msg": "ok"
    }

    {
        "code": 404,
        "data": null,
        "msg": "post not found" //正常应该不会有这种情况
    }
    ````

#### 个人隐私相关 
<br>

1. `PUT`设置自己的主页，私信可访问性`/api/v1/b/privacy-settings`

    主页功能、关注功能、私信功能 的开放设置

    默认均为关闭

    <br>

    **param list**
    - `profile_visibility` Integer  `0`不可见，`1`可见
    - `followable` Integer  `0`不可关注，`1`可关注
    - `message_permission` Integer  `0`不可私信，`1`可私信
    
    <br>

    **返回示意**

    ````
    {
        "code": 200,
        "data": null,
        "msg": "update privacy-settings success"
    }
    ````

    <br>

2. `GET`获取自己的主页，私信可访问性`/api/v1/b/privacy-settings`

    获取主页功能、关注功能、私信功能 的开放设置
    <br>

    **param list**

    `null`
    <br>

    **返回示意**
    ````
    {
        "code": 200,
        "data": {
            "profileVisibility": 1,
            "followable": 0,
            "messagePermission": 1,
        },
        "msg": "ok"
    }
    ````

    <br>

#### 关注粉丝相关 
<br>

1. `POST`关注用户`/api/v1/b/following/{uid}`

    关注别人，会检查可关注，封禁性

    <br>

    **param list**
    - `uid` Long 目标用户id

    <br>

    **返回示意**
    ````
    {
        "code": 200,
        "data": null
        "msg": ”ok“    //成功
    }

    {
        "code": 21001,
        "data": null
        "msg": "Not Followable" //不可关注
    }

    {
        "code": 21002,
        "data": null
        "msg": "Banned" //封禁
    }
    
    {
        "code": 21003,
        "data": null
        "msg": "repeat follow" //重复关注
    }
    ````
    <br>

2. `DELETE`取消关注用户`/api/v1/b/following/{uid}`

    取消关注别人

    <br>

    **param list**

    - `uid` Long 目标用户id

    <br>

    **返回示意**
    ````
    {
        "code": 200,
        "data": null
        "msg": ”ok“    //成功
    }

    {
        "code": 21004,
        "data": null
        "msg": "You are not following this user"    //你还没关注他
    ````

#### 通知
<br>

1. `GET`获取关注通知`/api/v1/f/message/follower`

    获取当前用户的关注通知
    支持分页查询，按照时间排序
    
    <br>

    **param list**
    - `page_disable` Integer 是否取消分页 默认`0`，不取消
    - `page`  Integer 页码 默认`1`
    - `page_size`  Integer 页大小 默认 `10`
    - `offset`  Integer 页偏移 默认 `0`
    - `unread_only`  Boolean 只查询未读信息

    <br>

    **返回示意**
    ````
    {
        "code": 200,
        "data": {
            "list": [
                {
                "uid": 1,
                "nickname": "张三",
                "avatarUrl": "upload/1223.jpg",
                "follow_at": "2026-01-01T12:34:56+08:00",
                "is_read": false,
                "read_at": null
                },
                {
                "uid": 2,
                "nickname": "李四", 
                "avatarUrl": "upload/234.jpg",
                "follow_at": "2026-01-02T15:31:46+08:00",
                "is_read": true,
                "read_at": "2026-01-04T15:31:46+08:00"
                }
            ], 
            "total": 2,
        }，
        "msg": ”ok“
    }
    ````
    **注：对于关注，取关，关注的情况，这里不合并关注通知，但是已读会全部已读。**

    <br>

2. `POST`已读指定关注通知

    `/api/v1/f/message/follower/read/{uid}`
    获取当前用户的关注通知
    支持分页查询，按照时间排序

    <br>

    **param list**
    - `uid` Long 关注者id

    <br>

    **返回示意**
    ````
    {
        "code": 200,
        "data": null,
        "msg": ”ok“
    }
    ````
    <br>

**注：**
- **对于关注，取关，关注的情况，这里不合并关注通知，但是已读会全部已读。**
- **原有API `POST`"全部已读"`/api/v1/f/message/all`,在这里依然生效**
